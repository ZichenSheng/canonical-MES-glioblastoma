# Signature resources

`signature_gene_sets.tsv` contains only gene sets used by the retained manuscript analyses. Neftel state and MES component programs are attributed to Neftel et al. (Cell, 2019); Hallmark and matrisome sets retain their source labels in the table. No historical candidate signature is included.

These definitions are provided to make score construction inspectable. Third-party gene sets remain subject to their original source terms and citation requirements.
