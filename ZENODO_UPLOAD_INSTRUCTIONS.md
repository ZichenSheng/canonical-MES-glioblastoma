# Zenodo archive steps

This local repository has not been uploaded or archived. After the GitHub repository is created:

1. Push the reviewed `main` branch and local `v1.0.0` tag to GitHub.
2. Create the GitHub release `v1.0.0 – Manuscript code release` without attaching datasets or project archives.
3. Connect the GitHub repository to Zenodo, enable `canonical-MES-glioblastoma`, and archive release `v1.0.0`.
4. Only after Zenodo issues a real DOI, add that DOI to `README.md` and `CITATION.cff` in a new commit.

No DOI has been assigned or asserted in this repository.
