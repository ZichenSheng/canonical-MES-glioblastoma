# Data availability

Raw datasets, processed expression matrices, patient-level tables, fitted BayesPrism objects, and download caches are not redistributed in this repository.

Public accessions and source pages are listed in `reproducibility/dataset_registry.tsv`. Users must obtain each dataset from its original repository and comply with the corresponding access conditions and terms of use. Some public source records provide processed rather than raw human data because of participant-privacy restrictions; the code expects the same public files used by the manuscript analysis.

The repository license applies only to the code and repository-authored documentation. It does not relicense third-party datasets or gene-set resources.
